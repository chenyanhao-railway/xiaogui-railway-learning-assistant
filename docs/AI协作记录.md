# 小轨线路工学习助手 AI协作记录

本记录对应本仓库的真实迭代过程。参赛视频中的AI过程复现应使用相同任务重新演示，不补造不存在的对话或提交历史。

## 迭代一：从通用学习助手转向线路工学习场景

### 人类目标

保留小轨已有的任务提醒、中文语音、免打扰时段和本地保存能力，把使用对象从泛化的“学生”改为高速铁路施工与维护专业学生，并把学习任务落到线路巡检、病害整治、起道拨道、伤损轨枕和冬季安全。

### 核心提示词

```text
把现有“小轨·主动学习助手”改造成“小轨·线路工学习助手”。

保留：
1. 主动提醒未完成任务
2. 识别临期和逾期任务
3. 中文语音与静音时段
4. 本地任务保存
5. 可选DeepSeek兼容接口

新增：
1. 线路巡检、起道拨道、轨枕道岔、冬季钢轨脆断风险的学习内容
2. 学习资料与现场作业规程的边界提示
3. 不生成具体施工操作步骤

不要虚构岗位资质、成绩或现场经验。
```

### AI建议与人工决策

AI建议保留原有任务管理结构，并先修改产品定位、默认任务和本地回复，而不重写整个程序。人工确认：

- 线路工知识只用于学习复习；
- AI不得替代课程、正式规章和现场判断；
- 首版不加入未经核实的招聘门槛和作业参数；
- 保留用户主动选择模型模式的权利。

### 落地结果

- 更新页面标题、主视觉和隐私说明；
- 默认任务改成线路工学习任务；
- 增加巡检、冬季风险、起道拨道和道岔相关本地回复；
- 模型系统提示增加安全边界；
- 对应Git提交：`feat: specialize Xiaogui for railway line worker learning`。

## 迭代二：增加线路工学习卡与快捷提问

### 人类目标

让用户不只会看到待办列表，还能直接打开学习卡，了解线路工任务名称、学习重点和风险边界，并快速向助手发起复习问题。

### 核心提示词

```text
在现有页面中增加四张可展开的线路工学习卡：
1. 线路巡检先看什么
2. 起道拨道是什么
3. 轨枕与道岔为什么要更换
4. 冬季作业的安全底线

增加三个快捷提问按钮：
今天先学什么、巡检要点、冬季风险。

保持现有视觉风格，兼顾手机和电脑。所有内容只用于学习，不输出施工步骤。
```

### AI建议与人工决策

AI建议使用原生`details`元素实现可展开卡片，复用现有视觉变量，并让卡片一次只展开一张。人工要求删除可能被理解为现场操作指令的内容，统一加上“回到课程和正式规范确认”的提醒。

### 落地结果

- 新增线路工学习卡；
- 新增快捷提问按钮；
- 新增卡片展开交互和移动端布局；
- 对应Git提交：`feat: add line worker knowledge cards and quick prompts`。

## 迭代三：增加自动测试和可复现说明

### 人类目标

确保其他评审者能启动程序，验证任务新增、完成和本地学习回复，而不是只能相信演示视频。

### 核心提示词

```text
为小轨添加一个不依赖第三方包的Node.js自动测试。
测试需要启动临时服务器，使用临时data.json，验证：
1. GET /api/tasks
2. POST /api/tasks
3. PATCH /api/tasks/:id
4. 巡检问题能否得到本地回复
5. 回复是否包含“不替代”的安全边界

另外写清楚10分钟复现步骤和模型环境变量。
```

### 人工验证

测试已在Node.js 22以上环境运行通过。测试使用独立端口和临时数据文件，不会污染真实任务数据。

### 落地结果

- 新增`test/smoke.test.mjs`；
- 新增`package.json`测试命令；
- 新增README快速开始、测试、数据隐私和10分钟复现；
- 对应Git提交：`test: add local API and knowledge reply smoke test`。

## 迭代四：建立待核实知识与学习复盘闭环

### 本轮真实目标

让“AI不能替代正式规范”从一句提示变成可操作的流程：学生遇到没有把握的知识点时，先把问题和来源记下来，向老师或正式资料核实后再标记完成；同时显示近7天的任务进度，解决“好像学了很多但无法检查”的问题。

### 录屏时使用的复现提示词

这条提示词是在本轮功能完成后整理出的可复现版本，不声称是逐字保存的原始输入。录屏时应重新输入，并展示AI的完整回答和人工修改。

```text
在现有小轨线路工学习助手中增加“待核实知识”和“近7天学习复盘”。

要求：
1. 每张线路工学习卡可以把一个待确认问题加入清单；
2. 问题记录来源，并能标记已核实、转回待核实或删除；
3. 任务完成时记录完成时间；
4. 汇总近7天已完成任务、待完成任务和待核实知识数量；
5. 数据保存在本地，不引入远程数据库；
6. 增加自动测试，验证新增问题、更新核实状态和完成任务；
7. 不生成现场作业参数或施工指令。
```

### AI建议与人工决策

AI建议把待核实问题作为独立本地数据保存，并让学习卡通过来源字段关联到问题。人工保留了“先记录、再核实”的流程，没有允许模型自动把答案标记为正确；复盘只展示可计算的进度，不评价学生能力。

### 落地结果

- 四张学习卡增加“加入待核实”入口；
- 新增待核实知识的新增、核实、转回和删除接口；
- 新增近7天完成、待完成和待核实数量；
- 任务完成时记录`completedAt`；
- 自动测试增加完成时间、知识新增和核实状态检查。
