# 小轨线路工学习助手演示视频脚本

目标时长：6分30秒至7分30秒，1920×1080，MP4。

视频中至少2分钟必须真实展示AI协同开发过程。不得补造Prompt、提交历史或运行结果。

## 00:00 至 00:30 问题

画面：浏览器首页和线路工学习任务。

讲解：高速铁路施工与维护专业的学习任务涉及巡检、病害、起拨道、轨枕道岔和冬季风险。资料分散、术语多，学生容易不知道下一步做什么。

## 00:30 至 01:40 产品演示

操作：

1. 点击“启动小轨”；
2. 添加一项“复习线路巡检观察要点”任务；
3. 点击快捷提问“巡检要点”；
4. 展开“冬季作业的安全底线”；
5. 把冬季风险加入待核实知识，演示“标记已核实”；
6. 查看近7天任务和知识复盘；
7. 完成一项任务并展示语音或状态变化。

讲解重点：主动提醒、本地保存、学习卡、待核实知识和本地规则回退。

## 01:40 至 04:10 AI协同过程复现

操作：

1. 在代码编辑器中打开AI对话和修改记录；
2. 重新输入“把小轨改造成线路工学习助手”的核心Prompt；
3. 展示AI建议的任务结构、内容边界和代码修改；
4. 展示一次真实Bug和修复Diff；
5. 运行自动测试。

建议展示的真实问题：

- 检查框完成后任务重新排序，需通过接口状态确认完成结果；
- favicon缺失造成无关404，通过增加空图标声明消除控制台错误；
- 模型接口不可用时必须回退到本地规则。

讲解重点：不是让AI一次生成全部代码，而是由人确定范围、拆功能、验收结果和删除不安全内容。

## 04:10 至 05:20 架构与可复现性

画面：架构图、README和终端测试。

讲解重点：

- 前端只负责交互；
- 模型密钥只在服务器；
- 任务保存在本机；
- 测试使用临时数据文件；
- 10分钟内可启动和复现。

## 05:20 至 06:10 学习价值

画面：学习卡和任务列表。

讲解重点：小轨不是铁路作业系统，不提供现场操作指令。它帮助安排学习、复习术语、记录待核实问题，并通过近7天复盘提醒回到课程和正式规章。

## 06:10 至 06:40 限制与下一步

讲解：页面关闭后提醒可能延迟；模型结果需要核实；后续会增加教师维护的知识来源、每周历史趋势和错题标签。
